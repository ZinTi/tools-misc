# tools-misc 桌面小工具杂项

## 一、说明

存放多个独立、简单、低维护的桌面图形化小工具、Web网页小工具、部分命令行小工具的仓库：这些工具独立松散，大多数为实验性、一次性工具，功能单一、轻量。


## 二、项目清单
| name          | language && library               | description                           |
|---------------|-----------------------------------|---------------------------------------|
| BallSimulator | C++, Qt6                          | 小球模拟器（C++ && Qt6）                |
| hello-grpc    | Rust, C++, Qt6, RPC ...           | RPC 示例程序                           |
| threshold     | HTML/CSS/JS                       | 调阈值网页小工具（下载自其他网站）          |
| GoServerDemo  | Golang                            | 静态文件服务器 demo                     |
| filebox       | Golang, HTML/CSS/JS               | 文件上传/下载服务器小工具，共享文本编辑工具  |
 --------------------------------------------------------------------------------------------
